# Alerta Seguro - Projeto Front-End

Projeto educativo para ajudar pessoas leigas a reconhecer sinais de golpes digitais.

## Páginas
- Início: apresentação do projeto.
- Checklist: avalia os hábitos de segurança marcados pelo usuário.
- Dicas: orientações simples para evitar golpes.
- Verificar link: procura sinais básicos de risco em um endereço.
- Mensagem suspeita: procura palavras e expressões comuns em mensagens de golpe.

## Pastas
Alerta_Seguro_Refeito/
├── html/ (cinco páginas HTML)
├── css/style.css
├── js/script.js
└── README.md


## Como executar
1. Extraia o ZIP.
2. Abra a pasta `Alerta_Seguro_Refeito` no VS Code.
3. Abra `html/index.html` e use o Live Server ou abra o arquivo no navegador.
4. Os arquivos CSS e JavaScript são carregados externamente por `../css/style.css` e `../js/script.js`.

## Observação
O checklist é uma avaliação educativa baseada nas respostas. O verificador de links e o analisador de mensagens usam regras e palavras-chave simples. Eles não consultam serviços externos, não confirmam fraudes e não garantem segurança. Em caso de dúvida, não clique, não pague e procure a empresa ou pessoa por um canal oficial.
