SEGURANÇA NA INTERNET

Bem-vindo ao Alerta Seguro!

A internet facilita muitas coisas, mas também existem pessoas que tentam enganar usuários para roubar dinheiro ou informações pessoais.

Este site ajuda pessoas que não entendem muito de tecnologia a reconhecer situações suspeitas e tomar decisões mais seguras.

O que você encontra aqui?

  • Checklist para avaliar seus hábitos.
  • Dicas simples para evitar golpes digitais.
  • Ferramenta para analisar links.
  • Ferramenta para analisar mensagens suspeitas.
Lembre-se: desconfie de mensagens que pedem pressa, dinheiro, senhas ou códigos de confirmação.
